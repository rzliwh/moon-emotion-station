## 一、背景与目标

当前场景只有月球 + 地球 + 随机星空，深空缺少"可信的宇宙感"。本次增加：

1. **太阳**（常驻）：不只是装饰——修正现有光照方向 bug，让"看地球"和"看太阳"成为两种情绪
2. **北斗七星**（常驻）：天球北极方向的可辨识星座，提供方向感和真实感
3. **行星解锁系统**（6 颗行星，按回信数解锁）：把"回信进度"视觉化为"你的情感星空在扩大"

**设计原则**：常驻天体负责真实感（这是一个可信的宇宙），解锁天体负责成长感（这个宇宙因你而丰富）。

## 二、现存问题（必须先修）

### 光照方向与视觉不符

```javascript
// js/scene/moon-scene.js setupLights() 现状
const sun = new THREE.DirectionalLight(0xffffff, 1.2);
sun.position.set(5, 3, 5);   // 光照从 +z 来
// 地球在 (0, 0.5, 8)          // 地球也在 +z
```

问题：月球亮面朝向地球方向，天文上是错的（满月时地球与太阳在月球两端）。

**修正**：视觉太阳放在地球反方向，DirectionalLight 同步改到该方向。效果：
- 玩家看地球 → 月面为暗面，地球挂在漆黑天幕 → 孤独感
- 玩家转身看太阳 → 月面被照亮，陨石坑阴影清晰 → 荒原感

createSun() {

## 六、北斗七星实现规格

### createBigDipper()（新增方法，init() 中调用）

挂在 `this.stars` Group 内，随星空整体旋转（现有 `stars.rotation.y += 0.00005`），勺形相对位置不变。

```javascript
createBigDipper() {
  // 勺形（归一化2D，斗勺→斗柄）：天枢/天璇/天玑/天权/玉衡/开阳/摇光
  const dipper2D = [
    [0, 0], [1, -0.3], [1.8, -0.9], [2.6, -0.8],
    [3.4, -0.4], [4.2, 0.2], [5.0, 0.9]
  ];

  const group = new THREE.Group();
  const R = 100;   // 天球半径
  const scale = 8; // 勺形放大倍数

  dipper2D.forEach(([dx, dy]) => {
    // 映射到天球北极方向 (0, 0.7, -0.7)
    const base = new THREE.Vector3(0, 0.7, -0.7).normalize();
    const pos = base.clone().multiplyScalar(R);
    pos.x += dx * scale;
    pos.y += dy * scale * 0.6;

    const star = new THREE.Mesh(
      new THREE.SphereGeometry(0.8, 8, 8),
      new THREE.MeshBasicMaterial({ color: 0xcfe0ff })
    );
    star.position.copy(pos);

    // 光晕：明显亮于普通星空（普通星 size 0.8 / opacity 0.8）
    const halo = new THREE.Mesh(
      new THREE.SphereGeometry(1.6, 8, 8),
      new THREE.MeshBasicMaterial({ color: 0xcfe0ff, transparent: true, opacity: 0.2, depthWrite: false })
    );
    star.add(halo);
    group.add(star);
  });

  this.stars.add(group);
}
```

**验收要点**：勺形必须在星海中一眼可辨。如果不够亮，优先加 halo opacity（0.2→0.3），不要加星体尺寸（会失真）。

const PLANET_DEFS = [

  { key: 'mars',    name: '火星',   radius: 0.08, distance: 7.5,  angle: 0.3,  unlockAt: 3,  baseOpacity: 0.5, color: 0xd4785c },

**说明**：angle 为弧度，行星位置 `x = sin(angle)*distance, z = cos(angle)*distance, y = 0.3`。整体偏 +z 半球（地球同侧），避开太阳方向。

### 7.2 纹理方案（风格化色块，不用 NASA 写实图）

`js/scene/textures.js` 新增 `createPlanetTexture(colorHex)`：程序化 Canvas 生成（256×128），底色 + 噪声条纹 + 极地略暗，与月球雷达站的调性一致。不新增外部图片资源，零 CORS 风险。

- 金星/木星/土星：横向条纹感
- 火星：红橙底 + 两极白斑
- 海王星/冥王星：纯色 + 轻微噪声即可

### 7.3 createPlanets()（新增方法）

```javascript
createPlanets() {
  this.planets = [];
  PLANET_DEFS.forEach(def => {
    const geo = new THREE.SphereGeometry(def.radius, 32, 32);
    // MeshBasicMaterial：遥远星光感，不受光照影响
    const mat = new THREE.MeshBasicMaterial({
      map: createPlanetTexture(def.color),
      transparent: true,
      opacity: 0,           // 初始隐藏
      depthWrite: false
    });
    const mesh = new THREE.Mesh(geo, mat);
    mesh.position.set(
      Math.sin(def.angle) * def.distance,
      0.3,
      Math.cos(def.angle) * def.distance
    );
    mesh.userData = def;

    // 土星环
    if (def.hasRing) {
      const ring = new THREE.Mesh(
        new THREE.RingGeometry(def.radius * 1.3, def.radius * 2, 64),
        new THREE.MeshBasicMaterial({ color: def.color, side: THREE.DoubleSide, transparent: true, opacity: 0, depthWrite: false })
      );
      ring.rotation.x = Math.PI * 0.35;
      mesh.add(ring);
      mesh.userData.ring = ring;
    }

    this.scene.add(mesh);
    this.planets.push(mesh);
  });
}
```

### 7.4 解锁逻辑

```javascript
// 检查并解锁（回信数变化时调用）
checkPlanetUnlocks(replyCount) {
  PLANET_DEFS.forEach(def => {
    if (replyCount >= def.unlockAt && !this.unlockedPlanets.has(def.key)) {
      this.unlockPlanet(def);
    }
  });
}

// 渐显动画：2秒 easeOutCubic 到 baseOpacity + 前半程呼吸闪烁
unlockPlanet(def) {
  const planet = this.planets.find(p => p.userData.key === def.key);
  if (!planet) return;

  this.unlockedPlanets.add(def.key);
  this.pendingPlanetUnlock = def; // 交给 UI 层弹提示

  const target = def.baseOpacity;
  const duration = 2000;
  const start = Date.now();
  const animate = () => {
    const t = Math.min(1, (Date.now() - start) / duration);
    const ease = 1 - Math.pow(1 - t, 3);
    let opacity = ease * target;
    if (t < 0.5) opacity += 0.3 * Math.sin(t * Math.PI * 4) * target; // 呼吸闪烁
    planet.material.opacity = Math.max(0, opacity);
    if (planet.userData.ring) planet.userData.ring.material.opacity = planet.material.opacity * 0.6;
    if (t < 1) requestAnimationFrame(animate);
  };
  animate();

  // 粒子爆发（复用现有 spawnParticles）
  spawnParticles({
    x: planet.position.x, y: planet.position.y, z: planet.position.z,
    count: 20, color: def.color, lifetime: 1.5, speed: 30, size: 1.5
  });
}
```
